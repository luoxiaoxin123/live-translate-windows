实时翻译（Live Translate）使用说明
====================================

安装版：双击 LiveTranslate-Setup-x64.exe 安装，然后从桌面或开始菜单打开「实时翻译」。
免安装版：解压 zip 后双击「实时翻译.exe」（程序本体在 app 文件夹内，不用进去）。

首次使用：打开「设置」页，填入你自己的 Google AI Studio API Key
（申请地址：https://aistudio.google.com/ ），点「保存并测试连接」。

回到「字幕」页，选目标语言和声音来源，点「启动字幕」。
播放外文视频或对着麦克风说话，悬浮字幕就会出现；
拖顶部小横条移动，拖右下角把手调大小。

提示：
- 若 Windows 提示「已保护你的电脑」，点「更多信息」→「仍要运行」。
- 系统要求：Windows 10 2004（64 位）及以上；无需安装 .NET 或其他运行库。
- 麦克风模式需要在 系统设置 → 隐私 → 麦克风 中允许桌面应用访问。
- 卸载：设置 → 应用 → 实时翻译 → 卸载。
